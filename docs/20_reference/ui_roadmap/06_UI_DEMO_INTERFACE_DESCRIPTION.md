# Описание интерфейса EpiOS в демо-режиме (v1.1 Pilot RC)

Этот документ содержит краткое описание всех видимых объектов и панелей пользовательского интерфейса Epistemic OS (`work-shell`) в демонстрационном режиме. Он служит справочным руководством для пользователей и средством обеспечения общего понимания интерфейса.

---

## 📁 1. Левая боковая панель (Sidebar)
Боковая панель обеспечивает глобальную навигацию, управление контекстом сессии и переключение ролей пользователей.

*   **Логотип EpiOS & Свертывание:** 
    *   Логотип в верхнем левом углу с индикатором терминала.
    *   Кнопка «...» (три вертикальные точки) для сворачивания панели в компактный режим (только иконки).
*   **Разделы навигации (Sidebar Items):**
    *   **Рабочее место (Workplace):** Переключает на основной интерактивный холст графа и панель свойств.
    *   **Обзор ADR (ADR Review):** Экран процесса анализа архитектурных решений, запусков симуляции и согласований.
    *   **Архив (Archive):** Просмотр архивированных рабочих пространств с возможностью их быстрого восстановления.
    *   **Телеметрия (Telemetry):** Заглушка для мониторинга системных метрик и синхронизации ядер.
*   **Список рабочих пространств (Active/Pinned Workspaces):**
    *   Список доступных графовых пространств.
    *   **Индикатор активности (WsDot):** Иконка в виде светящейся фиолетовой молнии (`Zap`) отмечает текущее активное пространство.
    *   **Контекстные действия:** Кнопки «Закрепить», «Переименовать», «Архивировать» и «Поделиться чатом» при наведении на элемент списка.
*   **Кнопка «+ Новое пространство» (New Workspace):** Инициализация нового нейросетевого ядра.
*   **Селектор личностей (Role Switcher / Identity Context):**
    *   Блок переключения ролей с отображением текущей активной персоны: **Viewer** (Наблюдатель), **Contributor** (Соавтор), **Approver** (Утверждающий), **Admin (Approver)** (Администратор).
*   **Блок сессии (Session Info & Меню пользователя):**
    *   Поле **Session: <username>**. По клику открывает всплывающее меню пользователя с тремя пунктами:
        1.  **Настройка (Settings):** Открывает модальное окно настроек (управление рабочими местами WP, роли, таблица назначений).
        2.  **Справка (Help):** Открывает интерактивное окно с описанием элементов интерфейса.
        3.  **Выход (Exit):** Завершает текущий сеанс и возвращает пользователя на экран авторизации (`AuthScreen`).

## 🎨 2. Основное рабочее пространство (Workspace Room / Workplace)
Главный рабочий экран, отображающий граф рассуждений и свойства выбранных элементов.

*   **Интерактивный холст графа (Graph Canvas):**
    *   Визуализирует дерево логических связей с помощью библиотеки `React Flow`.
    *   **Узлы графа (Nodes):**
        *   **Hypothesis (Гипотеза):** Обозначается синим цветом и иконкой знака вопроса.
        *   **Evidence (Свидетельство):** Обозначается зеленым цветом и иконкой галочки.
    *   **Выделение узлов:** Клик по узлу плавно выдвигает правую панель свойств.
*   **Панель свойств интеллекта (Properties Panel - Правая панель):**
    *   **Заголовок:** Номер и тип узла (`#HYPOTHESIS` / `#EVIDENCE`).
    *   **Содержимое (Core Content):** Основной текст утверждения.
        *   *Кнопка «Edit»:* Позволяет соавторам и утвердителям предлагать изменения текста (создавать `Patch`).
    *   **Прослеживаемость (Epistemic Traceability):** Проверка криптографического подтверждения источника происхождения данных (через адаптеры MCP).
    *   **Оценка источника (Rating Panel):** Интерактивная шкала доверия к источнику с возможностью голосовать (`Cast Vote`) и видеть средний балл.
    *   **Кнопки действий (Purge / Redact / Propose Patch):**
        *   *Purge:* Полное удаление узла из графа (только для роли `Approver` / `Admin`).
        *   *Redact:* Маскирование чувствительных данных (PII / email) на базе регулярных выражений (только для роли `Admin`).

## ⚡ 3. Нижний статус-бар (Footer)
Информационная панель в самом низу экрана.

*   **Левая часть:** Название текущего рабочего пространства. При клике открывает всплывающую панель **Mission Panel**, где отображается цель задачи, связанный документ и метаданные.
*   **Правая часть (EPIOS_SHELL_CONNECTED):** Индикатор подключения к ядру. При наведении курсора мыши открывается панель с деталями системы:
    *   Статус базы данных (например, `POSTGRESQL_READY`).
    *   Версия Kernel API (`v1.0.0-PROD`).
    *   Сетевая задержка (`Latency: 12ms`).
    *   Статус защищенного анклава (`SECURE_ENCLAVE_ACTIVE`).

## 📊 4. Экран обзора ADR (ADR Review Workspace)
Специализированное рабочее пространство для анализа документов архитектурных решений (ADR).

*   **Левая колонка (ADR Index):**
    *   Поисковая строка для быстрой фильтрации решений.
    *   Список ADR с индикаторами статуса (**Proposed** / **Accepted**).
*   **Панель содержимого ADR:**
    *   **Информационная шапка:** ID решения, дата создания, имя автора, приоритет (`P0`, `P1`, `P2`) и текущий статус.
    *   **Интерактивные кнопки действий:**
        *   **Run Epistemic Analysis:** Запуск симуляции архитектурных рисков (сопровождается анимацией загрузки).
        *   **Approve Decision:** Утверждение решения (переводит статус в *Accepted*).
        *   **History:** История изменений ADR.
        *   **Governance:** Переключает экран в режим сплит-панелей управления:
            *   *Readiness Assessment (Панель готовности):* Оценки рисков, блокираторы и метрики качества.
            *   *Artifact Patch Panel:* Список предложенных патчей и diff-просмотр изменений.
            *   *Governance Panel:* Список голосов ревьюеров и форма для голосования.
            *   *Approval Panel:* Статус согласования.
        *   **Artifact:** Просмотр финальной, сгенерированной разметки ADR.
        *   **External Approval (Внешнее согласование):** Интеграция с внешним сервисом через защищенный мост MCP-протокола (`SecureMcpIframe`).

## 🗄️ 5. Экран Архива (Archive View)
Панель управления деактивированными рабочими пространствами.

*   **Список архивов:** Отображает название пространства, дату архивации и комментарий системы/пользователя (например, *«Архивировано пользователем»*).
*   **Восстановление:** Кнопка **Восстановить (Restore)** возвращает пространство в список активных и переводит в статус `running`.
